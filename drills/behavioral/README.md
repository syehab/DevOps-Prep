# Behavioral drills

Six timed spoken answers. Each drill is one prompt, 8 minutes to write, 3 minutes to say out loud. Then hints, then a model STAR in `<details>`. No gotchas. Write your answers in **your ShopSphere repository** under `docs/behavioral/`.

Cost: **USD 0.00**.

Use with Day 21, Day 30, and Day 40. The model answers use ShopSphere names so they stay consistent with the labs. Replace them with **your** facts before a real interview. Do not memorize a story you did not live.

## How to run one drill

1. Start an 8-minute timer.
2. Read **Prompt** only. Fill the STAR boxes in `docs/behavioral/<id>.md`.
3. Stand up. Speak the story in 3 minutes. Record yourself if you can.
4. Score with [RUBRIC.md](RUBRIC.md). Then open Hints and Solution.

STAR means: Situation, Task, Action, Result. Action is the longest box. Result needs a number or a named change.

## Interview use

Pick 01 and 04. A Senior story names evidence, blast radius, and the fix in Git. A Lead story names the system you changed so the next person does not repeat the night.

> **Remember:** Do not invent an outage. Use a lab (Day 41, broken-cluster) if you lack a work story, and say it is a lab.
