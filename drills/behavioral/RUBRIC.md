# Behavioral rubric

Score each story from 0 to 5. A Senior pass is **4**. Drill 04 needs **4** on both altitudes.

| Score | Meaning |
|:--|:--|
| 0 | Tool list. No time. No you. |
| 1 | Situation only. "We used Kubernetes." |
| 2 | Task exists. Action is "I worked with the team." |
| 3 | Action names your checks. Result is vague ("it got better"). |
| 4 | STAR is complete. Evidence first. Blast radius named. Result has a number or a Git change. |
| 5 | Same as 4, plus you name what you stopped doing so the class of failure cannot return.

## Lead versus Senior (drill 04)

| Altitude | Senior | Lead |
|:--|:--|:--|
| Unit of work | This incident, this PR | This class of incident, this policy |
| Identity | I ran the commands | I set who may run them |
| Success | Service restored, postmortem filed | Repeat rate dropped, review is in Git |
| Trap | Only the hero debug | Only the org chart, no technical meat |

You must be able to do **both**. A Lead who cannot debug is not a Lead in this course. A Senior who cannot raise the altitude stalls at the next level.
