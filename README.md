# DevOps-Prep

Day-by-day lessons for Senior / Lead DevOps preparation. Simple English, mental models, Azure and AWS side by side.

## Start here

1. **New to the material?** Read [Day-1-DevOps-Mental-Model-Concise.md](Day-1-DevOps-Mental-Model-Concise.md), then follow the Day files in order (Day-1 to Day-41).
2. **Preparing for interviews?** Open [jd-insights/README.md](jd-insights/README.md). Short pattern cards built from real job descriptions, each linking back to the Day lessons that teach it.
3. **Two files for the same Day?** Days 8, 9, 10, and 24 each exist in two versions. Open these first: [Day-8-L08](Day-8-L08-Infrastructure-as-Code.md), [Day-9-L09](Day-9-L09-IaC-Modules-Environments.md), [Day-10-L10](Day-10-L10-Terraform-State-Enterprise-Workflow-Final.md) (the files the [INDEX](jd-insights/INDEX.md) links), and for Day 24 the [Expanded file](Day-24-AZ-03-Azure-Advanced-Networking-Expanded.md). The other copies remain for reference.

> **Remember:** The Day lessons are the curriculum. jd-insights tells you what employers ask and where to study it.
